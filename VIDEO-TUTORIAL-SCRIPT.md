# TLH AI Skill Hub — Video Tutorial Script

**Estimated length:** 3-4 minutes
**Recording tool:** Loom, QuickTime, or any screen recorder with mic
**URL to open:** https://truelegacyhomes.github.io/tlh-skill-hub/

---

## INTRO (10 seconds)

**Screen:** Browser open to the Skill Hub home page

**Narration:**
"Hey team — this is the TLH AI Skill Hub. It's your go-to reference for every AI skill we've built at True Legacy Homes. I'm going to walk you through how to use it in about three minutes."

---

## SECTION 1: THE HOME PAGE — SKILL CATALOG (60 seconds)

**Screen:** Home page, scroll slowly to show the full layout

**Narration:**
"When you first land on the site, you'll see the Skill Catalog. This is a grid of every skill in our taxonomy."

**Action:** Point out the stats bar

**Narration:**
"At the top you'll see quick stats — how many total skills we have, how many are active and ready to use, how many are still in draft, and how many are planned for the future."

**Action:** Click in the search bar, type "automation"

**Narration:**
"You can search for any skill by name or keyword. For example, if I type 'automation,' it instantly filters down to show me just the Automation Planner."

**Action:** Clear the search, then click the 'All Series' dropdown, select 'Blueprints'

**Narration:**
"You can also filter by series. We have four series: Foundation skills are the core knowledge base — company info, brand guidelines, tools we use. Blueprints are the skills you'll use most — they help you define problems, plan products, create SOPs, and more. Engineering Standards and Toolkit are for the technical team."

**Action:** Click the 'All Statuses' dropdown, select 'Active'

**Narration:**
"And you can filter by status. Active means it's ready to use right now. Draft means it's built but still being refined. Planned means it's on our roadmap but not built yet — you'll see those cards are grayed out and can't be clicked."

**Action:** Clear all filters back to 'All'

---

## SECTION 2: SKILL DETAIL PAGES (45 seconds)

**Action:** Click on the "2.01 Problem Definer" card

**Narration:**
"Let's click into a skill to see what's inside. I'll open the Problem Definer — this is one of our most-used skills."

**Action:** Slowly scroll through the detail page

**Narration:**
"Every skill page has the same layout. At the top you see the series badge, status, skill ID, and a one-line summary of what it does."

**Action:** Point out the metadata grid

**Narration:**
"Below that is the metadata — who this skill is for, the version number, when it was last updated, and which series it belongs to."

**Action:** Scroll down into the content

**Narration:**
"Then you get the full documentation. This includes when to use the skill, the step-by-step interview process, emphasis guides showing which sections matter most, the output format, related skills, and troubleshooting tips. Everything you need to use the skill effectively is right here."

**Action:** Scroll to the bottom, click "Back to all skills"

**Narration:**
"And you can always click 'Back to all skills' at the bottom to return to the catalog."

---

## SECTION 3: SKILL FINDER (45 seconds)

**Action:** Click "Finder" in the top navigation

**Narration:**
"Now here's my favorite feature — the Skill Finder. If you're not sure which skill you need, this will figure it out for you."

**Action:** Read through the options briefly

**Narration:**
"It asks you one simple question: What are you trying to do? You've got eight options — define a problem, build something new, automate a workflow, document a process, create a report, request a system change, improve our AI skills, or look up company information."

**Action:** Click "Build something new"

**Narration:**
"Let's say I want to build something new. I click that, and it immediately shows me the recommended skills in the exact order I should use them. In this case, it says start with the Problem Definer to scope the problem, then use the New Product Planner to plan it out, and finally the Engineering Handoff Brief to package it for the engineering team."

**Action:** Click one of the recommended skill cards

**Narration:**
"Each recommendation is clickable — it takes you straight to that skill's full documentation."

**Action:** Navigate back to Finder, click "Start over"

**Narration:**
"You can click 'Start over' anytime to try a different goal."

---

## SECTION 4: COMMON WORKFLOWS (45 seconds)

**Action:** Click "Workflows" in the top navigation

**Narration:**
"Last but not least — Common Workflows. These are the most common multi-skill chains we use at TLH."

**Action:** Scroll through the workflows slowly

**Narration:**
"Each workflow shows you a real scenario — like starting a new project from scratch, creating an SOP, building an automation, requesting a system change, creating a report, or building a new skill."

**Action:** Point to the numbered steps in a workflow

**Narration:**
"For each workflow, you see the exact skills to use and in what order. Step one, step two, step three — with a brief description of what you do at each step. And every step links directly to that skill's documentation."

**Action:** Click on one of the step links to show it navigates to the skill

**Narration:**
"Click any step and it takes you right to the skill page so you can get started."

---

## SECTION 5: WRAP UP (15 seconds)

**Action:** Navigate back to home page

**Narration:**
"That's the Skill Hub. Bookmark it, share the link with your team. The site updates automatically whenever we add or change skills, so it's always current. If you're ever unsure which skill to use, start with the Finder. If you know what you need, search the catalog. And if you're working on a common project type, check the Workflows page for a step-by-step guide. Questions? Reach out to Jeff."

---

## RECORDING TIPS

- **Tool:** Loom (free) is the easiest — it records your screen and mic together
- **Resolution:** Make sure the browser window is at least 1280px wide so cards display in a 3-column grid
- **Speed:** Go slow. Pause for 1-2 seconds after each click so viewers can see what changed
- **Cursor:** Move your cursor to point at things as you mention them
- **Length target:** 3-4 minutes total
